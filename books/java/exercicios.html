Como usar este caderno

Cada módulo corresponde a uma fase ou trilha do curso, com a lista das aulas que ele cobre. As perguntas conceituais pedem explicações com as suas palavras; os exercícios de código pedem programas completos: escreva, compile e execute cada um.

Tente sempre resolver sozinho antes de abrir o Caderno de Respostas. É no erro que o conhecimento fixa.

    Ponto(int x, int y) { this.x = x; this.y = y; }
    @Override public boolean equals(Object o) {
        return o instanceof Ponto p && p.x == x && p.y == y;
    }
    @Override public int hashCode() { return 31 * x + y; }
}

    final String cor;
    PontoColorido(int x, int y, String cor) { super(x, y); this.cor = cor; }

}
