Q17

Pattern matching

O que este método devolve para um Ebook de 30 reais, para um LivroFisico de 0,5 kg e para null? Por que a ordem dos casos importa?

static decimal Frete(Produto? p) => p switch
{
    null => throw new ArgumentNullException(nameof(p)),
    Ebook => 0m,
    LivroFisico { PesoKg: <= 1 } => 10m,
    LivroFisico l => 10m + (decimal)(l.PesoKg - 1) * 5m,
    _ => 15m,
};
