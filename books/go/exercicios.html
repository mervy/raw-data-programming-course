Como usar este caderno

Cada módulo reúne um bloco de aulas do curso, com a lista dos artigos que ele cobre. As perguntas conceituais pedem explicações com as suas palavras; os exercícios de código pedem programas: escreva, rode com go run e teste com go test -race.

Tente sempre resolver sozinho antes de abrir o Caderno de Respostas. É no erro que o conhecimento fixa.
